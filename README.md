# Księga Henocha — czytnik (PWA)

Offline'owy czytnik **1 Księgi Henocha (etiopskiej)** w polskim przekładzie: 108 rozdziałów,
1064 wersetów, 315 przypisów. Rodzina aplikacji sayd1975-code (wspólny ciemny motyw).

## Funkcje
- 📚 Spis treści w układzie pięciu ksiąg (Czuwający 1–36, Przypowieści 37–71,
  Astronomiczna 72–82, Sny 83–90, List 91–108)
- 📖 Czytanie rozdziałami; przypisy otwierane dotknięciem przy wersecie
- 🔍 Szukaj w całej księdze z przejściem do wersetu
- 🔖 Zakładki i ✏️ notatki do wersetów (tylko localStorage — nic nie wychodzi z urządzenia)
- ↩ „Czytaj dalej”, 🎲 losowy werset, A−/A+ rozmiar czcionki, motyw ciemny/jasny/systemowy
- 📴 Pełny offline (service worker; po zmianie plików podbij CACHE_NAME w sw.js)
